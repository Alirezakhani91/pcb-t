PCB&T V14 — GITHUB PAGES FIX (FLAT FILE LAYOUT)

All files in this folder belong DIRECTLY at the root of the pcb-t repository.
Do NOT create css/, js/ or assets/ folders for this version.

How to update:
1. In GitHub, open your existing pcb-t repository.
2. Choose Add file -> Upload files.
3. Drag all files INSIDE the extracted PCBT_GitHub_Flat_Fix folder (not the folder itself).
4. Confirm overwrite/update for existing files and Commit changes.
5. Verify Settings -> Pages -> Deploy from branch -> main -> /(root).
6. Once deployed, open https://alirezakhani91.github.io/pcb-t/ and press Ctrl+Shift+R.

If you already uploaded photos, the separate patch ZIP contains ONLY rewritten HTML, CSS and JavaScript;
you may upload that patch instead.

The contact form still uses mailto (not a true server-side contact form).
