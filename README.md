# PCB&T | Artistic Brand Edition V14

25 independent HTML pages. All CSS, JS and images are bundled locally.

## Open
Extract this ZIP completely, then double-click `index.html`. Do not run a single HTML file directly from inside a ZIP archive. For deployment to GitHub Pages, upload the site folder contents at the repository root or in the `docs/` directory, then configure the publishing source.

## Key files
- `index.html` — homepage; `services.html`, `industries.html`, `about.html`, `contact.html` and the rest are independent pages.
- `css/v14-art.css` — new art direction and motion.
- `js/v14-art.js` — animated SVG strokes, scroll reveal and subtle pointer illumination.
- `assets/pcbt-logo.png` — original UNMODIFIED transparent brand logo.
- `assets/brand/sunrays-from-original-logo.png` — decorative extraction of the exact existing golden ray pixels, used only as a subtle watermark.
- `V14_ART_DIRECTION_FA.md` — Persian design notes.
- `V14_Visual_Concept.jpg` — conceptual composite, not a browser screenshot.

## Important launch items
The contact form currently opens an email draft through the user's email application; connect a secure form backend before production. Verify Privacy wording and ensure any tax/support claims match the company's actual licensed services. Imagery is mostly AI-generated photorealistic imagery; replace with commissioned or properly licensed real photography if a fully documentary look is mandatory.

## Testing caveat
HTML and asset paths, JS syntax, and unmodified logo SHA256 were checked. An actual graphical browser run was blocked in the execution environment; live browser QA on desktop, mobile, and reduced-motion settings remains recommended.
